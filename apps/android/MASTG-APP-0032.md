A sample application demonstrating the @MASTG-TOOL-0146 library, a root checking library for Android. The app provides a simple interface to test various root detection techniques including checking for root management apps, dangerous apps, root cloaking apps, test keys, dangerous properties, BusyBox and su binaries, and read-write system partitions. Available on Google Play for quick testing of root detection capabilities.

> The library uses both Java and native checks to detect root, making it more difficult to cloak. See the [RootBeer repository](https://github.com/scottyab/rootbeer) for implementation details and limitations.
