title: HTTP Toolkit
platform: network
source: https://httptoolkit.com
---

HTTP Toolkit is an open-source tool designed to intercept, analyze, and debug HTTPS traffic. The tool captures HTTP traffic from Android, iOS, web or desktop applications.

It comes in a (limited) free version and paid version with additional features. HTTP Toolkit allows you to set up its CA certificate and disable SSL pinning via Frida and is also able to intercept HTTP requests from Flutter. In the free version it is not possible to set an up-stream proxy to re-direct the HTTP traffic to a penetration testing tool like BurpSuite.

Instead of HTTP Toolkit, you can rely on the tools mentioned in @MASTG-TECH-0109.
