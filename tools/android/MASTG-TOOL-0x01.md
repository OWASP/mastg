KernelSU is a kernel-based Android root solution. Like @MASTG-TOOL-0021, it provides root access without modifying the system partition. Its manager app lets you grant root access to selected apps and manage modules.

KernelSU requires a compatible device and kernel; installation differs by device. Check the [official installation guide](https://kernelsu.org/guide/installation.html) before installing it.
