id: MAS-ASSET-UD-U
title: User Data in Use
---

This asset type covers user data that is loaded into the application's memory or shown on screen at runtime, for example while it is decrypted, processed, displayed, or typed by the user.

## Examples

- PII loaded into memory for display or processing, such as names, account numbers, or health records.
- User credentials or PINs present in memory or on screen during authentication flows.
- Session tokens, JWTs, or OAuth tokens held in memory while the user is logged in.
- Decrypted financial or health data in the application's address space.
- Content visible in screenshots, notifications, overlays, or the pasteboard.
