## MAS-ASSET-UD-U: User Data in Use

This asset category covers user data that is loaded into an application's memory during runtime. User data in use includes any personal, financial, health, or authentication information the application decrypts, processes, or holds in its address space.

### Examples

- PII loaded into memory for display or processing (e.g., names, account numbers, health records)
- User credentials or PINs present in memory during authentication flows
- Session tokens, JWTs, or OAuth tokens held in memory while the user is logged in
- Decrypted financial or health data in the application's address space during processing
- Key material present in memory while encrypting or decrypting user data
