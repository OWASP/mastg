## MAS-ASSET-UD-R: User Data at Rest

This asset category covers user data that is stored persistently on a device. User data at rest includes any personal, financial, health, or authentication information the application writes to files, databases, or other data stores.

### Examples

- Personally Identifiable Information (PII) stored in local databases or files (e.g., names, Social Security numbers, addresses)
- Financial or health records persisted in application storage
- User credentials, PINs, or biometric templates stored in the keychain, keystore, or shared preferences
- Session tokens, JWTs, or OAuth tokens written to persistent storage
- Key material used to encrypt user data stored on the device
