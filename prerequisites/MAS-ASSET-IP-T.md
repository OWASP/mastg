## MAS-ASSET-IP-T: Intellectual Property Data in Transit

This asset category covers intellectual property data that is transmitted between the application and a remote endpoint, or between processes on the device. Intellectual property data in transit includes any technical or proprietary information exchanged over a network or via interprocess communication (IPC).

### Examples

- API keys, secrets, or certificates transmitted in request headers or bodies when the application authenticates itself to its own backends
- API keys, secrets, or certificates sent to third-party services during service authentication (e.g., Crashlytics, Google Maps)
- Encryption keys or key material exchanged during key agreement or key transport protocols
- Proprietary configuration or licensing data transmitted between the application and a remote server
