---
id: MAS-ASSET-UD-T
title: User Data in Transit
---

This asset type covers user data that is transmitted between the application and a remote endpoint, or between processes on the device via interprocess communication (IPC).

## Examples

- PII submitted to backend services, such as names, Social Security numbers, or account details.
- User credentials or PINs transmitted during login or account recovery flows.
- Session tokens, JWTs, or OAuth tokens included in API requests.
- Financial or health data sent to remote servers or third-party SDKs.
- User data passed to other apps or components through intents, content providers, or other IPC channels.
