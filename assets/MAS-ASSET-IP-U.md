id: MAS-ASSET-IP-U
title: Intellectual Property Data in Use
---

This asset type covers intellectual property data that is loaded into the application's memory at runtime, for example while it is decrypted, processed, or sent to a system API.

## Examples

- API keys, secrets, or certificates held in memory while the application authenticates itself to its own backends or to third-party services.
- App-wide encryption keys present in memory while data is being encrypted or decrypted.
- Values that the app writes to logs, the pasteboard, or a WebView from memory.
