id: MAS-ASSET-UD-R
title: User Data at Rest
---

This asset type covers user data that is stored persistently on the device, such as in files, databases, shared preferences, keyboard caches, or the keychain/keystore.

## Examples

- Personally Identifiable Information (PII) stored in local databases or files, such as names, Social Security numbers, or addresses.
- Financial or health records persisted in application storage.
- User credentials, PINs, or biometric templates stored in the keychain, keystore, or shared preferences.
- Session tokens, JWTs, or OAuth tokens written to persistent storage.
- Key material derived from or bound to a specific user, such as a key derived from the user's password.
